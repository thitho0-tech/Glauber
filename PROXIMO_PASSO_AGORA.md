```
      Vê ROADMAP_ATUALIZADO_V2, seção 'Tasks Detalhadas'.
      Expande cada task com acceptance criteria, story points, 
      dependências. Mostra resultado."
Claude: [Entrega 15 tasks bem estruturadas]
```

### 2. Cada Conversa em Cowork = Documento
```
Conversa 1: "Quebrar tasks" → Documento TASKS_SPRINT1A.md
Conversa 2: "Schema SQL" → Documento SCHEMA_SPRINT1A.md
Conversa 3: "React interfaces" → Documento REACT_SPRINT1A.md
...
Final: Consolidar tudo em BRIEF_SPRINT1A.md

Não tente fazer TUDO numa conversa.

```

```
Semana 2: "DP, validar que task 1A.1 tem AC correto?"

```

### 4. Lembre dos Documentos Que Já Existem
```
Não comece do zero. Tudo já está em:
  - ROADMAP_ATUALIZADO_V2_SPRINT1A_PRIORIDADE.md (specs)
```
