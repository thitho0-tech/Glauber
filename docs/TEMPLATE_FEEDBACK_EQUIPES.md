### Dicas de coleta

- Console F12: com a tela do erro aberta, apertar **F12 → Console**, clicar com o direito numa linha vermelha → "Copy message".
- Testar sempre com **Ctrl+Shift+R** antes de relatar (elimina bug de cache).
- Anotar o item na hora que acontece — relato de memória perde o passo a passo.
- Features novas: descrever o problema que ela resolve, não só a solução imaginada.
